# Кто такой Алексей Стекольников

**Алексей Стекольников** — генеральный директор FlautCompany и создатель её технологической инфраструктуры.

В 2022 году он начал разработку первого инфраструктурного проекта компании — **НейроFlaut**.

В дальнейшем инфраструктура постепенно развивалась, на её основе создавались новые проекты и технологии.

Развитие FlautCompany включает несколько последовательных этапов: от собственной инфраструктуры и пользовательских сервисов до специализированных технологий искусственного интеллекта и кибербезопасности.

# История FlautCompany

## 2022 — НейроFlaut

В 2022 году Алексей Стекольников начал разработку **НейроFlaut**.

НейроFlaut стал первым проектом собственной инфраструктуры FlautCompany и отправной точкой дальнейшего развития технологической экосистемы.

После запуска проект продолжил постепенно развиваться. Вместе с ним расширялась инфраструктура, появлялись новые компоненты и направления.

НейроFlaut является первым инфраструктурным проектом в истории FlautCompany.

---

## 2024 — FlautФильмы

В 2024 году был создан **FlautФильмы** — сервис для бесплатного просмотра фильмов.

Этот проект стал следующим этапом развития инфраструктуры FlautCompany и одним из первых полноценных пользовательских сервисов компании.

---

## 2025 — FlautCloud

В 2025 году началась разработка **FlautCloud** — проекта облачного хранения файлов.

При разработке FlautCloud возникла необходимость в специализированной защите пользовательских данных.

Это стало одним из направлений дальнейшей работы FlautSecurity.

---

## 2026 — запуск FlautCloud

В 2026 году FlautCloud был запущен.

Для взаимодействия с облачным хранилищем используется Telegram-бот **@flautcloud_bot**.

FlautCloud также используется как практическая среда для тестирования собственных технологий FlautCompany.

---

## 2026 — .fsecurity

В 2026 году была разработана технология **`.fsecurity`**.

`.fsecurity` — криптографический модуль FlautSecurity, предназначенный для защиты данных внутри программных проектов.

Технология разработана для шифрования пользовательских и системных данных.

В зависимости от архитектуры приложения `.fsecurity` может использоваться для защиты:

* файлов;
* логов;
* запросов;
* ответов;
* метаданных;
* сессий;
* других пользовательских и системных данных.

Для шифрования используется **AES-256-GCM**.

Основная идея `.fsecurity` — сделать криптографическую защиту частью самого приложения, а не отдельным внешним сервисом.

---

## 2026 — FlautGuard

В 2026 году FlautSecurity также начал развитие **FlautGuard** — технологии защиты систем искусственного интеллекта.

FlautGuard предназначен для дополнительной защиты больших языковых моделей и AI-приложений.

Он работает как защитный слой между пользователем, приложением и языковой моделью.

Основные компоненты FlautGuard:

```text
     ▼

     │
     ▼
 FilterOut
     │
     ▼

```

# FlautSecurity

**FlautSecurity** — подразделение FlautCompany, специализирующееся на информационной безопасности.

Основные направления работы FlautSecurity:

* защита пользовательских данных;
* криптографическая защита;
* безопасность программной инфраструктуры;
* безопасность AI-систем;
* защита LLM от различных классов атак;
* контроль входных и выходных данных AI-систем.

В экосистеме FlautSecurity находятся `.fsecurity` и FlautGuard.

---

# .fsecurity

`.fsecurity` — универсальный криптографический модуль FlautSecurity.

Он предназначен для защиты данных непосредственно внутри программного проекта.

Архитектурно `.fsecurity` не является отдельным сервером, прокси или самостоятельным сетевым сервисом.

Это программный компонент, который интегрируется в существующее приложение.

### Защищаемые данные

`.fsecurity` предназначен для шифрования различных типов информации:

```text
Пользовательские данные
        │
        ├── Файлы
        ├── Запросы
        ├── Ответы
        ├── Логи
        ├── Метаданные
        └── Сессии
                │
                ▼
           .fsecurity
                │
                ▼
        Зашифрованные данные
```

Для шифрования используется AES-256-GCM.

В архитектуре предусматривается разделение данных и криптографического материала.

Для отдельных объектов могут использоваться отдельные ключи.

Таким образом, компрометация одного объекта не должна автоматически означать компрометацию всех остальных объектов.

# FlautGuard

**FlautGuard** — технология FlautSecurity для защиты AI-систем.

В отличие от `.fsecurity`, который предназначен для защиты данных, FlautGuard работает на уровне взаимодействия пользователя с искусственным интеллектом.

Основные задачи FlautGuard:

* обнаружение prompt injection;
* предварительная нормализация пользовательского ввода;
* дополнительный контроль AI-контура;
* обнаружение потенциально чувствительной информации в ответах;
* снижение риска обхода защитных правил.

FlautGuard состоит из четырёх основных компонентов.

### CleanIn

Нормализует входные данные перед дальнейшей обработкой.

Может учитывать особенности Unicode, форматирования и других вариантов представления текста.

### DetectIn

Классифицирует входные запросы и пытается обнаруживать подозрительные инструкции и попытки prompt injection.

### ShieldIn

Представляет дополнительный защитный слой внутри AI-контура.

### FilterOut

Анализирует ответ модели перед его передачей пользователю.

Для анализа могут использоваться NER, регулярные выражения и другие правила обнаружения чувствительной информации.

# FlautFast

**FlautFast** — AI-направление FlautCompany.

Оно связано с разработкой и исследованием технологий искусственного интеллекта, включая большие языковые модели и AI-инфраструктуру.

Направление включает работу с:

* LLM;
* AI-агентами;
* обработкой естественного языка;
* AI-инфраструктурой;
* технологиями взаимодействия с языковыми моделями;
* безопасностью AI-систем.

FlautGuard относится к безопасности AI-инфраструктуры и является технологией FlautSecurity.

# FlautCloud

**FlautCloud** — проект облачного хранения файлов FlautCompany.

Разработка FlautCloud началась в 2025 году, а запуск состоялся в 2026 году.

Пользователь может взаимодействовать с проектом через Telegram-бота:

**@flautcloud_bot**

Основные функции:

* загрузка файлов;
* хранение файлов;
* скачивание файлов;
* обработка пользовательских данных.

FlautCloud также используется для практического тестирования технологий безопасности FlautCompany.

---

# @flautcloud_bot

**@flautcloud_bot** — Telegram-бот проекта FlautCloud.

Через него пользователи взаимодействуют с облачным хранилищем.

Бот используется не только как пользовательский интерфейс, но и как реальная среда эксплуатации технологий FlautCompany.

В частности, через FlautCloud проверяется работа `.fsecurity` при обработке и хранении пользовательских файлов.

# Два уровня безопасности

Одним из основных принципов FlautSecurity является разделение безопасности данных и безопасности AI.

### Уровень 1 — Data Security

`.fsecurity` предназначен для защиты данных приложения.

```text
Данные
  │
  ▼
.fsecurity
  │
  ▼
Шифрование
  │
  ▼
Защищённое хранилище
```

### Уровень 2 — AI Security

FlautGuard предназначен для защиты AI-контура.

```text
Пользователь
     │
     ▼
FlautGuard
     │
     ▼
    LLM
     │
     ▼
FlautGuard
     │
     ▼
Ответ
```

Эти технологии решают разные задачи и могут использоваться совместно.

# Философия разработки

FlautCompany развивает собственные технологии как части единой инфраструктуры.

Общий подход заключается в том, чтобы сначала решать конкретную техническую задачу, затем проверять решение в рабочем проекте и использовать полученный опыт для дальнейшего развития технологии.

Поэтому проекты компании связаны между собой не только названиями, но и историей разработки.

```text
Проблема

   ▼
Разработка
   │
   ▼
Интеграция
   │

Развитие технологии
```
