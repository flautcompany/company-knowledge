## FlautCompany

**Название:** FlautCompany
**Генеральный директор:** Алексей Стекольников
**Основные направления:** программная инфраструктура, искусственный интеллект, кибербезопасность, защита данных и облачные технологии.

Компания развивает как самостоятельные продукты, так и программные модули, предназначенные для интеграции непосредственно в существующие проекты.

# FlautSecurity

**FlautSecurity** — подразделение FlautCompany, специализирующееся на разработке технологий информационной безопасности.

Основные направления FlautSecurity включают защиту программных приложений, пользовательских данных и систем искусственного интеллекта.

В экосистему FlautSecurity входят собственные разработки, в том числе `.fsecurity` и `FlautGuard`.

---

## .fsecurity

**`.fsecurity`** — криптографический модуль FlautSecurity, предназначенный для защиты данных непосредственно внутри программного проекта.

Модуль может использоваться для защиты различных типов информации:

* пользовательских файлов;
* запросов;
* ответов;
* логов;
* метаданных;
* сессий;
* других данных приложения.

Для шифрования используется **AES-256-GCM**.

Основная архитектурная идея `.fsecurity` заключается в том, что пользовательские данные хранятся в зашифрованном виде, а ключевой материал отделён от самих данных.

`.fsecurity` не является отдельным сервером, прокси или самостоятельным сетевым сервисом. Это программный компонент, который может быть встроен непосредственно в существующее приложение.

---

## FlautGuard

**FlautGuard** — технология безопасности для систем искусственного интеллекта, разработанная FlautSecurity.

FlautGuard располагается между пользователем и языковой моделью и выполняет последовательную обработку входных и выходных данных.

Архитектура включает четыре основных компонента:

```text id="3phw3y"
Пользователь
     │
     ▼
  CleanIn
     │
     ▼
  DetectIn
     │
     ▼
LLM / ShieldIn
     │
     ▼
 FilterOut
     │
     ▼
  Ответ
```

### CleanIn

Слой предварительной обработки входных данных.

Предназначен для нормализации пользовательского ввода и снижения эффективности состязательных вариантов атак.

### DetectIn

Компонент обнаружения подозрительных входных запросов.

В частности, используется для выявления попыток prompt injection и других вариантов манипуляции входными инструкциями.

### ShieldIn

Дополнительный защитный слой внутри AI-контура.

В архитектуре FlautGuard используются механизмы дополнительного контроля внутренних компонентов модели.

### FilterOut

Финальный уровень проверки ответа.

Для анализа выходных данных могут использоваться NER, регулярные выражения и другие правила обнаружения чувствительной информации.

# FlautFast

**FlautFast** — AI-направление FlautCompany, связанное с разработкой технологий искусственного интеллекта и больших языковых моделей.

В рамках FlautFast рассматриваются:

* большие языковые модели;
* AI-агенты;
* инфраструктура для AI;
* методы взаимодействия с LLM;
* технологии безопасности AI-систем.

FlautGuard является частью технологического направления, связанного с защитой систем искусственного интеллекта.

---

# FlautCloud

**FlautCloud** — проект облачного хранения файлов, созданный FlautCompany.

Проект позволяет пользователям загружать и скачивать файлы через Telegram-бота:

**@flautcloud_bot**

FlautCloud также используется как практическая среда для тестирования технологий FlautCompany.

В частности, проект используется для проверки `.fsecurity` в условиях реальной эксплуатации.

Таким образом, FlautCloud одновременно является самостоятельным программным проектом и экспериментальной площадкой для технологий компании.

---

# Связь технологий

Технологии FlautCompany разрабатываются как взаимосвязанные компоненты единой экосистемы.

```text id="zr6v7n"
                         FlautCompany
                              │
              ┌───────────────┼───────────────┐
              │               │               │
              ▼               ▼               ▼
        FlautSecurity        AI        Инфраструктура
              │               │               │
        ┌─────┴─────┐         │               │
        ▼           ▼         ▼               ▼
   .fsecurity  FlautGuard  FlautFast      FlautCloud
        │           │
        ▼           ▼
      Данные        AI
    безопасность  безопасность
```

`.fsecurity` отвечает за защиту данных.

`FlautGuard` — за дополнительный уровень безопасности AI-систем.

`FlautFast` — за разработку AI и LLM-технологий.

`FlautCloud` используется для разработки, эксплуатации и практического тестирования технологий компании.

# Подход FlautCompany к разработке

FlautCompany рассматривает безопасность и программную инфраструктуру как систему взаимосвязанных уровней.

Защита данных, безопасность искусственного интеллекта и безопасность приложений рассматриваются как отдельные задачи, которые могут дополнять друг друга.

Одним из принципов разработки является создание технологий, которые можно интегрировать непосредственно в существующие программные проекты без необходимости полностью менять их инфраструктуру.
