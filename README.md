# FlautSecurity

**FlautSecurity** — подразделение FlautCompany, занимающееся кибербезопасностью и защитой программных систем.

Основные направления FlautSecurity:

* защита пользовательских данных;
* криптографическая защита;
* защита файлов;
* безопасность программной инфраструктуры;
* защита AI-систем;
* безопасность LLM;
* обнаружение prompt injection;
* анализ входных данных;

Наиболее заметные технологии FlautSecurity:

Таким образом, FlautSecurity развивает два связанных направления: защиту данных и защиту искусственного интеллекта.

# .fsecurity

**`.fsecurity`** — криптографический модуль FlautSecurity.

Он предназначен для интеграции непосредственно в программный проект.

`.fsecurity` не является отдельным сервером, прокси или самостоятельным сетевым сервисом.

Основная задача модуля — защита данных приложения посредством шифрования.

В зависимости от архитектуры проекта `.fsecurity` может защищать:

* пользовательские файлы;
* запросы;
* ответы;
* логи;
* метаданные;
* сессии;
* другие пользовательские и системные данные.

Основной криптографический алгоритм — **AES-256-GCM**.

Одним из архитектурных принципов `.fsecurity` является разделение данных и криптографического материала.

Для отдельных объектов могут использоваться отдельные ключи.

Это позволяет уменьшить потенциальные последствия компрометации отдельного объекта и не использовать один универсальный ключ для всей системы.

`.fsecurity` является технологией FlautSecurity и используется в инфраструктуре FlautCompany.

# FlautGuard

**FlautGuard** — технология FlautSecurity для защиты систем искусственного интеллекта и больших языковых моделей.

В отличие от `.fsecurity`, который отвечает за защиту данных, FlautGuard работает на уровне AI-контуров.

Основные задачи:

* защита от prompt injection;
* анализ пользовательского ввода;
* нормализация входных данных;
* дополнительный контроль AI-систем;
* анализ ответов LLM;
* обнаружение потенциальных утечек чувствительной информации.

Архитектура FlautGuard включает четыре основных компонента:

```text
Пользователь
     │
     ▼
  CleanIn
     │
     ▼
  DetectIn
     │
     ▼
  ShieldIn
     │
     ▼
    LLM
     │
     ▼
 FilterOut
     │
     ▼
 Пользователь
```

### CleanIn

Предварительная нормализация входного текста.

Компонент предназначен для обработки нестандартных вариантов представления пользовательского ввода.

### DetectIn

Классификация пользовательских запросов.

Основной класс угроз — попытки prompt injection и изменения ожидаемого поведения модели посредством пользовательских инструкций.

### ShieldIn

Дополнительный защитный слой внутри AI-контура.

Он предназначен для усиления защиты самой системы, а не только анализа текста пользователя.

### FilterOut

Анализ результата работы модели.

Для обнаружения потенциально чувствительных данных могут использоваться NER, регулярные выражения и другие правила.

# Два уровня безопасности

Одним из принципов архитектуры FlautSecurity является разделение защиты данных и защиты AI.

## Уровень 1 — Data Security

`.fsecurity` защищает данные приложения.

```text
Данные
  │
  ▼
.fsecurity
  │
  ▼
Шифрование
  │
  ▼
Защищённое хранение
```

## Уровень 2 — AI Security

FlautGuard защищает AI-контур.

```text
Пользователь
     │
     ▼
FlautGuard
     │
     ▼
    LLM
     │
     ▼
FlautGuard
     │
     ▼
Ответ
```

Эти два уровня решают разные задачи и могут использоваться совместно.

# Подход к безопасности

FlautCompany рассматривает безопасность как отдельный технологический слой инфраструктуры.

При этом безопасность не ограничивается одним механизмом.

Разные компоненты решают разные классы задач.

`.fsecurity` предназначен для защиты данных.

FlautGuard предназначен для защиты AI-систем.

Такое разделение позволяет применять специализированные механизмы безопасности в зависимости от объекта защиты.

```text
                 Безопасность
                      │
             ┌────────┴────────┐
             │                 │
             ▼                 ▼
        Data Security      AI Security
             │                 │
             ▼                 ▼
        .fsecurity          FlautGuard
```

# Краткая справка

**FlautCompany** — технологическая компания, созданная вокруг собственной программной инфраструктуры.

Компания развивает несколько направлений, включая IT-инфраструктуру, искусственный интеллект, облачные технологии и кибербезопасность.

Таким образом, текущая технологическая экосистема FlautCompany включает программную инфраструктуру, пользовательские сервисы, облачное хранение, искусственный интеллект и специализированные технологии безопасности.
