# .fsecurity

**Категория:** кибербезопасность / защита данных
**Разработчик:** FlautSecurity / FlautCompany
**Тип:** программный модуль

`.fsecurity` — криптографический модуль, предназначенный для защиты данных непосредственно внутри программного проекта.

Технология используется для шифрования пользовательских и системных данных.

К защищаемым данным относятся:

* файлы;
* запросы;
* ответы;
* логи;
* метаданные;
* сессии;
* другие данные приложения.

Для шифрования используется AES-256-GCM.

Одной из архитектурных особенностей является использование отдельных криптографических ключей для объектов и разделение зашифрованных данных и ключевого материала.

`.fsecurity` не является отдельным сервером или сетевым сервисом. Он интегрируется непосредственно в приложение.

# FlautGuard

**Категория:** кибербезопасность / AI Security
**Разработчик:** FlautSecurity / FlautCompany
**Тип:** программный модуль

FlautGuard предназначен для дополнительной защиты систем искусственного интеллекта и больших языковых моделей.

Модуль располагается в AI-контуре между пользовательским вводом и моделью и выполняет обработку входных и выходных данных.

Архитектура включает четыре основных компонента:

```text id="k1m4cx"
Пользователь
     │
     ▼
  CleanIn
     │
     ▼
  DetectIn
     │
     ▼
    LLM
     │
  ShieldIn
     │
     ▼
 FilterOut
     │
     ▼
 Пользователь
```

### CleanIn

Нормализация и предварительная обработка входных данных.

### DetectIn

Обнаружение подозрительных запросов, включая попытки prompt injection.

### ShieldIn

Дополнительный защитный слой внутри AI-контура.

### FilterOut

Анализ результатов модели с использованием механизмов обнаружения чувствительной информации.

# FlautFast

**Категория:** искусственный интеллект
**Разработчик:** FlautCompany
**Тип:** технологическое направление

FlautFast — направление FlautCompany, связанное с искусственным интеллектом и большими языковыми моделями.

В рамках направления рассматриваются и разрабатываются:

* LLM;
* AI-агенты;
* AI-инфраструктура;
* системы обработки естественного языка;
* технологии взаимодействия с языковыми моделями;
* механизмы безопасности AI.

FlautGuard связан с FlautFast как защитный компонент AI-инфраструктуры.

---

# FlautCloud

**Категория:** облачные технологии
**Разработчик:** FlautCompany
**Тип:** программный проект

FlautCloud — проект облачного хранения файлов.

Пользователь может взаимодействовать с системой через Telegram-бота:

**@flautcloud_bot**

Основные функции проекта:

* загрузка файлов;
* хранение файлов;
* скачивание файлов;
* обработка пользовательских данных.

FlautCloud также используется как практическая среда для тестирования технологий FlautCompany.

В частности, проект применяется для проверки работы `.fsecurity` в реальных сценариях.

---

# @flautcloud_bot

**Категория:** Telegram-бот
**Связан с проектом:** FlautCloud

`@flautcloud_bot` — интерфейс взаимодействия с FlautCloud через Telegram.

Через бота пользователь может загружать и получать обратно файлы.

Бот также используется в качестве рабочей среды для тестирования технологий защиты данных.

Таким образом, `@flautcloud_bot` является частью проекта FlautCloud, а не отдельным направлением деятельности FlautCompany.

# Взаимодействие .fsecurity и FlautGuard

`.fsecurity` и FlautGuard относятся к FlautSecurity, но решают разные задачи.

`.fsecurity` работает на уровне данных.

FlautGuard работает на уровне искусственного интеллекта.

Это позволяет разделить защиту инфраструктуры на два независимых слоя:

```text id="s8v1qa"
                Приложение
                    │
          ┌─────────┴─────────┐
          │                   │
          ▼                   ▼
     FlautGuard          .fsecurity
          │                   │
     AI Security         Data Security
          │                   │
          ▼                   ▼
        LLM                Данные
```

Использование этих технологий вместе позволяет одновременно контролировать безопасность AI-взаимодействия и защиту хранимых данных.

# Практическое тестирование

FlautCompany использует собственные проекты для проверки разрабатываемых технологий.

FlautCloud является одним из таких проектов.

В нём `.fsecurity` применяется для защиты файлов и пользовательских данных, что позволяет проверять технологию в условиях реальной эксплуатации.

Аналогичный принцип применяется к AI-технологиям: FlautGuard развивается и тестируется как компонент AI-инфраструктуры.
